# MemoFigure — Product Story

## The idea

Photos preserve how a moment looked, but many meaningful memories begin as feelings, fragments, or stories. MemoFigure explores a different form of remembrance: describe a moment in ordinary language and receive a personal 3D keepsake that can live in a collection.

The experience begins with one memory and an optional set of photos. MemoFigure then turns that starting point into a keepsake that can be revisited as part of a personal collection.

## Core design decisions

### Keep creation simple

Natural text is the primary input. Photos can add visual context, but they are optional.

### Make the journey clear

MemoFigure presents creation as a small number of calm, understandable stages so people always know what is happening.

### Turn one result into a lasting collection

Each result belongs to a personal gallery where it can be revisited alongside the memory that inspired it.

### Let a memory continue

“Continue This World” lets a finished keepsake inspire new directions, allowing related memories to grow into a connected series.

## My contribution

I created the product concept, designed the experience and visual identity, built the iPhone app, and prepared its public website and App Store launch.

## Product outcome

MemoFigure is available on the U.S. App Store with a public website, a memory-to-3D experience, personal galleries, and connected keepsake series.
